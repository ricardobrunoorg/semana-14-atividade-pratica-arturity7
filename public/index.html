Sobre

Este site foi criado como Trabalho Prático da disciplina de Desenvolvimento Web. O tema escolhido foi o Mozilla Firefox — navegador open-source que marcou a internet desde 2004. O projeto apresenta as principais versões do Firefox e as extensões mais importantes de cada época, com dados servidos por um backend JSON Server e consumidos via Fetch API.
